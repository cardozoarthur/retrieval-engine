# R09 — distribuição pública reproduzível

Estado: ativa. Como consumidor, quero clonar e testar a fonte pública.

Aceites: licença, documentação, clone anônimo da main, build e testes no clone,
mesmo SHA remoto e remoção da cópia original após verificar preservação.
Contratos e API permanecem conforme os schemas da versão 0.1.0. Credenciais
ficam no keyring. Publicar fonte, fixtures e instruções, com artefatos gerados
ignorados. A falha em qualquer verificação preserva a árvore original.
BDD: dado um clone sem credenciais, os comandos documentados compilam e passam.
Usar testes existentes, pois a publicação não modifica o motor.
