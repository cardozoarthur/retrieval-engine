# R09 — distribuição pública reproduzível

Estado: publicação e reconstrução verificadas. Como consumidor, quero clonar e testar a fonte pública.

Aceites: licença, documentação, clone anônimo da main, build e testes no clone,
mesmo SHA remoto e remoção da cópia original após verificar preservação.
Contratos e API permanecem conforme os schemas da versão 0.1.0. Credenciais
ficam no keyring. Publicar fonte, fixtures e instruções, com artefatos gerados
ignorados. A falha em qualquer verificação preserva a árvore original.
BDD: dado um clone sem credenciais, os comandos documentados compilam e passam.
Usar testes existentes, pois a publicação não modifica o motor.

## Evidência de publicação

Em 2026-11-04, um clone HTTPS sem credenciais da revisão
`febc770cb8e979d4f61770fd86d32171b3b373f4` compilou no Windows x64 com Rust 1.96.
A consulta BM25 do README retornou JSON válido e os hashes dos PDFs de teste
coincidiram com os originais. O script de preparação baixou o E5 e verificou
os hashes dos recursos sem depender da instalação anterior.

Os comandos serializados do README aprovaram 97 testes regulares e 14 com
inferência real. A primeira execução paralela falhou por prazo em
`task_deadline_record_eviction_and_worker_drop_release_source_leases`. O
teste passou isolado e na suíte serial completa. O validador JSON aceitou
16 casos válidos e rejeitou 18 inválidos.

O commit posterior registra esta evidência e atualiza somente documentação.
A remoção local é verificada após conferir a revisão pública final.
